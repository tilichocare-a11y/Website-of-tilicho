Put your product videos in this folder, then set the file names in main.js (TILICHO.videos).

Tips for fast loading on mobile data:
- MP4 (H.264), 720p, 15-40 seconds, under ~5 MB each.
- Optional poster image (JPG/WebP, about 1200x800) shown before the video plays.
- Or upload to YouTube and paste only the video ID into main.js instead.
